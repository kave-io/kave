* /backend-api/wham/apps/ : ChatGPT apps passthrough (trailing slash)
* /backend-api/codex/wham/apps : ChatGPT Codex apps passthrough
* /backend-api/codex/wham/apps/ : ChatGPT Codex apps passthrough (trailing slash)
* /connectors/directory/list : ChatGPT connectors directory passthrough
* /connectors/directory/list/ : ChatGPT connectors directory passthrough (trailing slash)
* /connectors/directory/list_workspace : ChatGPT connectors workspace directory passthrough
* /connectors/directory/list_workspace/ : ChatGPT connectors workspace directory passthrough (trailing slash)

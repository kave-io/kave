The killer feature you described — cost prediction
How a freelancer quotes a client project with Kaveh
Step 1 — describe requirements
Freelancer defines what the agent needs to do: read emails, respond to customers, update CRM entries
kaveh simulate --task "email-triage"
Step 2 — Kaveh runs a simulation
Kaveh simulates the workflow against real model pricing — estimates token usage per run, per day, per month
Estimated: ~2,400 tokens/run × 50 runs/day
Step 3 — cost range output
Kaveh outputs a cost band: low estimate (cheap model), recommended (balanced), high estimate (premium model)
$18–$45/month depending on model choice
Step 4 — freelancer quotes confidently
Client gets a predictable monthly cost in their quote. No surprises. Budget enforced by Kaveh in production automatically.
Budget cap set → agent throttles before overspending
